## Color Scheme

### Severity Alert Box Colors:
- **Critical** (≥3 repairs in 3 months):
  - Background: #fef2f2 (light red)
  - Border: #ef4444 (red)
  
- **Warning** (2 repairs in 3 months):
  - Background: #fff7ed (light orange)
  - Border: #f97316 (orange)
  
- **Info** (1 repair in 3 months):
  - Background: #fffbeb (light yellow)
  - Border: #f59e0b (yellow)

### Table Colors:
- **Header**: #003087 (STI Blue) with white text
- **Alternating Rows**: #f8f9fa (light gray)
- **Footer**: #f0f0f0 (gray) with bold text

### Text Colors:
- **Primary**: #003087 (STI Blue)
- **Success/Cost**: #28a745 (Green)
- **Ticket Numbers**: #003087 (Blue)
- **Dates**: #666 (Gray)

### Ticket Item Styling:
- Background: #f8f9fa (light gray)
- Left Border: #0d6efd (blue), 3px
- Border Radius: 3px
- Padding: 4px 8px

## Typography

### Font Sizes:
- **Body**: 10px
- **Headers (h2)**: 18px
- **Section Titles (h3)**: 14px
- **Summary Values**: 18px (bold)
- **Summary Labels**: 9px
- **Table Headers**: 10px (bold)
- **Table Data**: 9px
- **Ticket Details**: 8px
- **Ticket Dates**: 7px
- **Footer**: 9px

### Font Weights:
- **Normal**: Body text, labels
- **Bold**: Headers, section titles, summary values, ticket numbers, costs

## Page Layout

### Margins:
- All sides: 20px
- Bottom extra: 80px (for footer)

### Sections:
1. **Letterhead**: Fixed at top, 3px blue border bottom
2. **Report Title**: Centered, gray background
3. **Alert Box**: Full width, colored border-left
4. **Summary**: 3 equal columns
5. **Tables**: Full width, scrollable content
6. **Footer**: Fixed at bottom, gray border top

### Page Breaks:
- After Damaged Parts Breakdown table
- Before Monthly Cost Breakdown

## Print Specifications

### Paper Size: A4 (210mm × 297mm)
### Orientation: Portrait
### Print Margins: 20px all sides
### Color Mode: Full color (or grayscale acceptable)

- High contrast text (black on white)
- Clear section headings
- Logical reading order
- Sufficient font sizes (minimum 7px)
